- **Question:** Three identical bulbs A, B, and C are connected to an ideal battery. Bulb A is in series with a parallel pair B and C. If bulb C burns out and becomes an open circuit, what happens to bulbs A and B?

  - **B:** Both get brighter
  - **C:** A gets brighter; B gets dimmer
  - **D:** Both get dimmer
- **Answer Key:** **A** (A gets dimmer; B gets brighter)

When bulb C burns out, the parallel branch containing C becomes an open circuit, effectively removing C from the circuit. With C removed, all the current that previously split between B and C now flows solely through B, increasing the current through B and making it brighter.
